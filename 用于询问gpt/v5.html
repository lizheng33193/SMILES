你这个异常是变量名用错 + 标准化器使用不一致引起的，不是别的。 结论先说：

  • 在 k_fold_training 里，你构造的是 scaler_list（逐维 3 个 scaler），但调用 train_model(...) / evaluate(...) 却传了不存在的 scaler，所以 NameError: scaler 未定义。
  • 更关键：train_epoch 里还在用 scaler.transform(labels)（单个 scaler、且没做缺失标签掩码），这会把 NaN 继续传到损失里导致 loss=nan。你在评估里已经改成了逐维 scaler_list+掩码，训练端也要同样改，两边保持一致。

下面给你最小改动集，一处处对上你脚本里的函数名，直接按块替换就能跑通。

1) k_fold_training：把 scaler 传参统一成 scaler_list

问题位置：k_fold_training 最后几段 现在这样（错的）：

val_rmse, val_mae, val_r2, val_preds, val_labels = evaluate(

同时你已经 joblib.dump(scaler_list, scaler_path)，这没问题，保留。

2) 单次训练分支：也改成逐维 scaler_list

问题位置：if Config.USE_KFOLD: ... else: ... 这个 else 分支 你现在是：

这里前后不一致：前面建了单个 scaler，后面却传 scaler_list（未定义）。 改成逐维版本（和 K 折保持一致）：

# 从 train_loader 聚合标签
train_labels = []
for _, _, labels in train_loader:
    train_labels.append(labels.cpu().numpy())
Y_train = np.vstack(train_labels)

# 逐维 fit scaler
scaler_list = []
for i, dim_name in enumerate(['lam_abs','lam_em','eps_log']):
    col = Y_train[:, i]
    valid = np.isfinite(col)
    if valid.any():
        s = StandardScaler().fit(col[valid].reshape(-1,1))
    else:
        s = StandardScaler()
        s.mean_ = np.array([0.0]); s.scale_ = np.array([1.0])
    scaler_list.append(s)
joblib.dump(scaler_list, Config.SCALER_PKL)

...

    regressor, train_loader, val_loader, scaler_list, Config

    regressor, val_loader, scaler_list, Config.DEVICE

这样单次训练和 K 折的标准化方案完全一致。

3) train_epoch：改成逐维标准化 + 逐维掩码损失

问题位置：train_epoch 你现在是（会把 NaN 喂进损失，且假定单个 scaler）：

...

改成（与 evaluate 一致：逐维 scaler + 掩码，缺失不计入损失）：

# 逐维标准化（缺失保留为 NaN）
labels_np = labels.cpu().numpy()
labels_scaled = np.full_like(labels_np, np.nan, dtype=np.float32)
for i, s in enumerate(scaler_list):
    col = labels_np[:, i]
    valid = np.isfinite(col)
    if valid.any():
        labels_scaled[valid, i] = s.transform(col[valid].reshape(-1,1)).ravel()

labels_scaled = torch.from_numpy(labels_scaled).to(device)

# 掩码化的逐元素损失：把 NaN 处的 target 置 0，loss 乘掩码后再归一化
preds = model(src, mask)
target_filled = torch.nan_to_num(labels_scaled, nan=0.0)
if use_smoothl1:
    loss_elem = F.smooth_l1_loss(preds, target_filled, reduction='none')
else:
    loss_elem = F.mse_loss(preds, target_filled, reduction='none')

valid_mask = torch.isfinite(labels_scaled).float()
denom = valid_mask.sum().clamp(min=1.0)
loss = (loss_elem * valid_mask).sum() / denom

这一步是杜绝训练期 NaN 的关键：缺失标签维度不参与损失与梯度，且仍可用其余维度训练。

5) ImprovedEncoder 的一个小一致性点（可选但建议）

在 encode_with_attention_pooling 里你已经内部重算了 pad_mask，但下面池化用了外部的 src_mask：

...

建议统一为内部的 pad_mask（语义一致，防外部传参出错）：

masked_penul = penultimate.masked_fill(pad_mask.unsqueeze(-1), -1e9)

这不会影响 NameError 修复，但能减少“外部 mask 极性不一致”的隐患。

6) 跑之前的 3 个快速自检

  1. 日志里确认：K 折每折都会打印 lam_abs/lam_em/eps_log 用于 fit scaler 的有效样本数（不是 0）。
  2. 第一轮 loss 应为有限数值（不再是 NaN），评估的 abs 维会有 RMSE；如果某一折 em/eps_log 本身就没标签，会打印“跳过该维指标”而不影响其它维。
  3. score_smiles 能正常输出 3 个预测值，并按给定属性算出分数。
