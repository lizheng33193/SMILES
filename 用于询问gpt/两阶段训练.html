先把问题点讲透（只针对 smiles2proc_v2.py）

P0：损失函数仍然等权，没有落实“abs >> em >> eps”的业务优先级

你虽然做了 log10(eps) 与缺失掩码，但训练时对三列是等权 MSE。在样本很少（151 条）且两列经常缺失的情况下，等权多任务会把最稳妥的解推向**“输出均值附近的常数”**——这正是你看到三列都在各自一个窄范围波动的根因之一。

P1：对“缺失标签的样本”，模型被要求也要输出值，但没有学习到“应该不输出”的机制

现在脚本里只是“缺失列不计入损失”。这会让模型在没有监督的那一列上输出一个靠近总体均值的值（因为回归头是共享表示），与你希望的“缺失 ⇒ 预测也尽量无值或极小值”冲突。要做到“缺失就尽量不输出”，需要在训练里显式引入存在性判别（classification gate），用“是否有该列标签”做监督，推理时用这个 gate 去抑制该列回归输出——目前脚本没有这条路。

P2：推理/评估阶段的fold ↔ scaler 严格对齐与集成

脚本里评估函数是“按当前 fold 的 scaler_list 做反标准化”，没问题；但你外部的测试/集成脚本如果把不同折的标准化预测先平均，再用“某一个”fold 的 scaler 去 inverse_transform，会再次把输出拉回均值。这也是你截图里“三列都在一个值附近”的常见诱因。建议严格“每折 inverse 再在原空间集成”（下面给出实现模板）。

P3：小数据 + 冻结编码器 + 头部偏小 → 容易欠拟合

现在编码器默认冻结、头部是 128 的两层 MLP；在 151 条样本上，欠拟合会表现为“标准化空间预测接近 0”，反标准化后就接近训练均值。必须先在标准化空间打印均值/方差确认是否是常数解坍塌（给了自检片段）。

你要的目标怎么做到（一步步落地）

目标 A：落实“abs >> em >> eps”优先级（在标准化/对数空间）

把 train_epoch 的等权 MSE 换成带权 + 缺失掩码的 MSE（仍在标准化空间里；第三列是 log10(eps)）：

# 任务权重：abs 明显更大（可从 [5.0, 2.0, 1.0] 起步）
task_w = torch.tensor([5.0, 2.0, 1.0], device=preds.device).view(1,3)

target     = torch.nan_to_num(labels_scaled, nan=0.0)
valid_mask = torch.isfinite(labels_scaled).float()
loss_elem  = (preds - target) ** 2

loss = (loss_elem * valid_mask * task_w).sum() / (valid_mask * task_w).sum().clamp_min(1.0)

这样：

  • 缺失列不参与损失；
  • abs 的梯度比 em/eps 更大，模型会优先把结构的大体框架学好（与你的业务一致）；
  • 在标准化空间算 loss，不再被不同量纲干扰。 （把这段替换你脚本里 train_epoch 的 loss 即可。）

目标 B：缺失列在推理时尽量不输出值（极小或空）

新增一个存在性判别（presence）头，只对 lam_em 和 eps 训练 BCEWithLogitsLoss（标签：该样本该列是否有真实值）。推理时用 sigmoid(p) 作为 gate 抑制回归输出。

模型结构改动（最小侵入）

class TrfmRegressor(nn.Module):
    def __init__(self, encoder_wrapper):
        super().__init__()
        D = 4 * encoder_wrapper.hidden_size
        self.encoder_wrapper = encoder_wrapper
        self.reg_head = nn.Sequential(nn.Linear(D, 128), nn.ReLU(), nn.Dropout(0.1), nn.Linear(128, 3))
        # 新增：存在性判别头（只输出 em/eps 的存在性）
        self.gate_head = nn.Sequential(nn.Linear(D, 64), nn.ReLU(), nn.Linear(64, 2))  # logits for [em, eps]

    def forward(self, src, mask=None):
        feats = self.encoder_wrapper.encode_batch(src, mask).to(next(self.reg_head.parameters()).device)
        y_std  = self.reg_head(feats)         # [B,3]  标准化空间的 [abs, em, log10(eps)]
        gates  = self.gate_head(feats)        # [B,2]  logits for presence of [em, eps]
        return y_std, gates

推理时的“抑制规则”（把回归值变成“极小或空”）

  • 先按你脚本原流程逐列反标准化得到 [abs, em, log10_eps]；

  • p = sigmoid(gate_logits)；对 em/eps 这样生成最终值：

    • 若 p < τ（如 0.5），输出 空（写 NaN）或一个很小的值： em_pred = NaN；eps_pred = ε_min（例如 1）；
    • 若 p ≥ τ，输出回归值（eps 记得 10** 还原）。

  • 若你不想返回空值而是“几乎忽略的小值”，可在 log 空间做 gating： eps_log = p * eps_log + (1-p) * log10(ε_min)，再 10**(eps_log)；em 可做线性 gating 或直接置为 em_min。

这一步让“数据里缺失的列”在推理时自然趋向空/极小，与业务期望一致，同时不会破坏训练的数值稳定性。

目标 C：推理/集成严格按 fold ↔ scaler 对齐

给你一段推理集成模板（逐折 inverse，再在原空间平均）：

def predict_ensemble(dataloader, fold_ids=(1,2,3,4,5), device='cuda'):
    all_preds = []
    for k in fold_ids:
        model_k = load_model(f'.../best_regressor_fold{k}.pth', device)  # 返回 y_std, gate_logits
        scalers = joblib.load(f'.../scaler_fold{k}.pkl')                  # 3 个列级 scaler
        model_k.eval()
        preds_fold = []
        with torch.no_grad():
            for src, mask, _ in dataloader:
                src = src.to(device)
                y_std, gates = model_k(src, mask)          # y_std: [B,3] (abs, em, log10_eps_std)
                y_std = y_std.cpu().numpy()
                # 反标准化到 log/原空间
                y_log = np.full_like(y_std, np.nan)
                for i,s in enumerate(scalers):
                    y_log[:, i] = s.inverse_transform(y_std[:, [i]]).ravel()
                y_raw = y_log.copy()
                y_raw[:,2] = np.power(10.0, y_log[:,2])    # eps 还原
                # presence gating
                p = torch.sigmoid(gates).cpu().numpy()     # [B,2]
                em_min, eps_min = 250.0, 1.0               # 业务允许的极小值
                tau = 0.5
                # em
                mask_em = (p[:,0] < tau)
                y_raw[mask_em,1] = np.nan                  # 或者设成 em_min
                # eps
                mask_eps = (p[:,1] < tau)
                y_raw[mask_eps,2] = eps_min
                preds_fold.append(y_raw)
        all_preds.append(np.vstack(preds_fold))
    # 原空间做折间平均（对 NaN 可用 nanmean）
    preds = np.nanmean(np.stack(all_preds, axis=0), axis=0)
    return preds

这一步可以直接消除“反标准化错配引起的均值化”。（注意：绝对不要在标准化空间先平均再用“某一个”scaler 去 inverse。）
