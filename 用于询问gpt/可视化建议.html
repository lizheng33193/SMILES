下面给你三种“可视化训练”的常用方案，按投入成本从低到高排好序；每种我都给了一句话说明 → 怎么接入到你现有的 smiles2proc_v3.py → 能看到什么图。直接把对应代码片段粘到你的脚本里就能用。

方案 A：TensorBoard（最推荐，接入最快）

一句话：用 PyTorch 自带的 SummaryWriter 把标量、直方图、学习率、PR 曲线都写到日志里；命令行 tensorboard --logdir ... 即可交互查看。

怎么接

  1. 初始化 Writer（建议每个 fold 单独一个子目录） 在 k_fold_training() 里、进入每个 fold 训练前加：
from torch.utils.tensorboard import SummaryWriter
logdir = os.path.join(Config.OUTPUT_DIR, f"tb_logs/fold_{fold_id}")
writer = SummaryWriter(log_dir=logdir)
  1. 在 train_epoch / evaluate 里写标量 假设你的 train_epoch() 返回一个 dict：
# 训练一个 epoch 结束后
writer.add_scalar("train/reg_mse", train_stats["reg_mse"], global_step=epoch)
writer.add_scalar("train/presence_bce", train_stats["presence_bce"], global_step=epoch)
writer.add_scalar("train/lr", optimizer.param_groups[0]["lr"], global_step=epoch)
writer.add_scalar("train/grad_norm", train_stats["grad_norm"], global_step=epoch)  # 你若统计了梯度范数

验证结束（evaluate() 的返回里有三列指标）：

# RMSE / MAE / R2 按列分别记录
for j, name in enumerate(["lam_abs","lam_em","eps"]):
    writer.add_scalar(f"val/{name}_rmse", val_stats["rmse"][j], global_step=epoch)
    writer.add_scalar(f"val/{name}_mae",  val_stats["mae"][j],  global_step=epoch)
    writer.add_scalar(f"val/{name}_r2",   val_stats["r2"][j],   global_step=epoch)

# 你在evaluate里已有“常数解检测”的std打印，可以顺便写入：
for j, name in enumerate(["abs_std","em_std","eps_std"]):
    writer.add_scalar(f"val/std_pred_{name}", val_stats["pred_std"][j], global_step=epoch)
  1. 可选：写预测分布与参数直方图（有助于看是否坍塌）
# 标准化空间预测的直方图（或原空间也可）
writer.add_histogram("val/pred_std_abs", val_outputs["pred_std"][:,0], global_step=epoch)
writer.add_histogram("val/pred_std_em",  val_outputs["pred_std"][:,1], global_step=epoch)
writer.add_histogram("val/pred_std_eps", val_outputs["pred_std"][:,2], global_step=epoch)

# 权重/偏置直方图（每隔若干epoch写一次即可）
for name, p in model.named_parameters():
    writer.add_histogram(f"params/{name}", p.data, global_step=epoch)
  1. 可选：存在性判别的 PR/ROC 曲线 evaluate() 里返回 presence_logits 与标签（1=有值/0=缺失），写：
from torch.utils.tensorboard.summary import pr_curve
# 伪代码：pos=1, neg=0 的二分类曲线
writer.add_pr_curve("val/presence_em",  labels_presence_em,  preds_presence_em,  global_step=epoch)
writer.add_pr_curve("val/presence_eps", labels_presence_eps, preds_presence_eps, global_step=epoch)

如果你手头没有布尔数组，也可以只记录 presence_auc、presence_ap 等标量。

  1. 训练/当前 fold 结束记得关闭
writer.close()
  1. 启动 TensorBoard
tensorboard --logdir ./outputs/tb_logs --port 6006

你能看到什么

  • Loss 曲线：train/reg_mse, train/presence_bce；
  • 学习率与梯度范数：train/lr, train/grad_norm；
  • 验证集指标：每列的 rmse / mae / r2；
  • 预测方差（常数解检测）：val/std_pred_abs/em/eps；
  • 预测直方图（看是否“只在一个值附近”）；
  • 存在性判别的 PR/ROC（看 gate 的可分性）；
  • 参数直方图（看是否爆炸/塌缩）。

方案 B：CSV 日志 + Matplotlib（离线也好用）

一句话：把每个 epoch 的指标写入 CSV；训练完用一段脚本画折线、散点、残差直方图，生成 PNG 存档。

怎么接

  1. 训练时存 CSV 在每个 epoch 末尾，把当前 fold 的指标追加到一个 df 并 to_csv：
row = {
    "fold": fold_id, "epoch": epoch,
    "train_reg_mse": train_stats["reg_mse"],
    "train_presence_bce": train_stats["presence_bce"],
    "val_abs_rmse": val_stats["rmse"][0],
    "val_em_rmse":  val_stats["rmse"][1],
    "val_eps_rmse": val_stats["rmse"][2],
    "val_abs_r2":   val_stats["r2"][0],
    "val_em_r2":    val_stats["r2"][1],
    "val_eps_r2":   val_stats["r2"][2],
    "lr": optimizer.param_groups[0]["lr"],
}
log_csv_path = os.path.join(Config.OUTPUT_DIR, f"logs_fold_{fold_id}.csv")
append_row_to_csv(log_csv_path, row)  # 你写个小工具，若不存在则写header
  1. 训练后画图脚本（示例）
import pandas as pd; import matplotlib.pyplot as plt
df = pd.read_csv("./outputs/logs_fold_1.csv")
plt.figure(); plt.plot(df["epoch"], df["train_reg_mse"]); plt.xlabel("epoch"); plt.ylabel("train_reg_mse"); plt.title("Fold1 Train Loss"); plt.savefig("./outputs/fold1_train_loss.png")
plt.figure(); plt.plot(df["epoch"], df["val_abs_rmse"]); plt.plot(df["epoch"], df["val_em_rmse"]); plt.plot(df["epoch"], df["val_eps_rmse"]); plt.xlabel("epoch"); plt.ylabel("RMSE"); plt.title("Fold1 RMSE"); plt.legend(["abs","em","eps"]); plt.savefig("./outputs/fold1_rmse.png")
  1. 预测-真值散点与残差直方图（在 evaluate() 末尾加个可选开关保存一批图）
# 假设 y_true, y_pred 是原空间（门控后）的一列
def scatter_and_residual(y_true, y_pred, name, out_png):
    import numpy as np, matplotlib.pyplot as plt
    mask = ~np.isnan(y_true) & ~np.isnan(y_pred)
    y, yhat = y_true[mask], y_pred[mask]
    plt.figure(); plt.scatter(y, yhat, s=8); plt.xlabel("True"); plt.ylabel("Pred"); plt.title(f"{name} scatter"); plt.savefig(out_png.replace(".png","_scatter.png"))
    plt.figure(); plt.hist(yhat - y, bins=40); plt.xlabel("Residual"); plt.title(f"{name} residual"); plt.savefig(out_png.replace(".png","_resid.png"))

你能看到什么

  • 训练/验证曲线（多列对齐）；
  • 学习率变化；
  • 每列的散点图（对角线是否明显）、残差分布（是否偏/厚尾）；
  • 方便发报告存档（PNG/CSV）。

方案 C：Weights & Biases（wandb）（云端协作）

一句话：几行代码接入云端面板，自动记录曲线、模型、系统资源，支持对比不同 run 与超参可视化。

怎么接

import wandb
wandb.init(project="smiles-multitask", name=f"fold{fold_id}", config=dict(lr=..., batch=..., weights=[5,2,1]))
# 训练中：
wandb.log({
  "epoch": epoch,
  "train/reg_mse": train_stats["reg_mse"],
  "val/abs_rmse": val_stats["rmse"][0],
  ...
})
# 训练后：
wandb.save(f"{checkpoint_path}/best_regressor_fold{fold_id}.pth")

需要 pip install wandb 并登录一次；如果团队多人协作看板，wandb 很方便。

你能看到什么

  • 与 TensorBoard 类似的曲线，但跨机器/跨实验的对比更容易；
  • 超参表格、并排对比不同 run；
  • 自动的系统资源曲线（显存/CPU/磁盘 IO）。

我建议你最少做这些（落地清单）

  • 在 k_fold_training 里给每个 fold 加一个 TensorBoard Writer；
  • 在 train_epoch/ evaluate 里按上面示例写 train/val 标量 和 预测方差；
  • 在 evaluate 里（可选）保存 散点/残差图（每 10 epoch 或最佳时保存一次即可）；
  • 启动 tensorboard --logdir ./outputs/tb_logs，实时看训练；
  • 训练完成后，用 CSV + Matplotlib 生成 可存档的 PNG（用在报告/邮件里）。

看图时怎么解读（给你三个最有用的图）

  1. val/RMSE 三曲线（abs、em、eps）

    • 下降→收敛正常；
    • abs 曲线应明显优于 em/eps，符合权重设计；
    • 若某列 RMSE 不动+val/std_pred 极小 ⇒ 常数输出，回去查损失/学习率/冻结配置。

  2. Pred vs True 散点

    • 越接近对角线越好；
    • 只是一条“窄带”且斜率明显<1 ⇒ 预测“收缩到均值”；
    • 右上角密集、左下角稀疏 ⇒ 模型在高值段更“保守”。

  3. Presence PR 曲线 / AP（em/eps）

    • 曲线越靠右上越好；
    • AP 高说明“该不该输出”学得好；结合门控阈值（0.5~0.7）调一调业务输出策略。
